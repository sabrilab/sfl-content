# Kit réseaux SFL, V2 (matières)

2 novembre 2026. Cuir bordeaux, maillot vert bouteille et olive, pelouse, terre, papier craie : tout est dessiné en code (`tex.py`). Le sigle SFL est brodé (point satin, relief, couture). Classements façon BOLA.

| Dossier | Fichiers | Taille |
|---|---|---|
| `profil/` | sigle brodé or sur cuir bordeaux ; brodé craie sur maillot vert bouteille | 1080 × 1080 |
| `posts/` | podium, classement, écarts, le but, dimanche 12 h 30, MVP, ton nom ici (recrutement), verdict, le lieu | 1080 × 1350 |
| `reels/` | le but, il te manque, il manque 1, podium | 1080 × 1920 |
| `youtube/` | miniature du Résumé | 1280 × 720 |
| `bannieres/` | YouTube 2560 × 1440 (zone sûre respectée), Twitch 1200 × 480, Twitch hors ligne 1920 × 1080 | |

Photos : 4 images générées sur Magnific (Seedream 5 Flash) le 02/11 à la demande de Sabri, utilisées ici en aperçu 512 px : **à remplacer par les fichiers pleine définition téléchargés depuis Magnific** (ou par les vraies photos de Poleed) avant publication. Le maillot généré a un numéro raté (« 2i »).

Couleurs : bordeaux `#5E1A24`, vert bouteille `#1E3B2C`, émeraude `#0F5A43`, olive `#6B6A34`, terre `#A65A34`, pelouse `#4C7A35`, craie `#EEE6D3`, or `#C9A03A` (fil `#D8B04A`), encre `#16130F`.
Typos : Archivo (titres), Instrument Serif italique (accent), JetBrains Mono (faits). Chiffres et prénoms d'exemple.

Régénérer : `python3 kit2.py && node render.cjs .`
